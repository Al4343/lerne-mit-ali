# Lerne mit Ali — النسخة الجديدة

تم تجهيز `index.html` كملف مستقل يحتوي التصميم والصور داخله، لذلك لا يحتاج إلى رفع مجلد `assets` لتظهر الصور في الموقع.

## أسهل طريقة لتحديث موقع GitHub Pages
1. نزّل ملف `lerne-mit-ali-index.html` من المحادثة.
2. افتح مستودع `Al4343/lerne-mit-ali` على GitHub ثم افتح `index.html` واضغط Edit (القلم).
3. إذا كان تعديل الملف الطويل من الهاتف صعباً، استخدم خيار **Add file → Upload files** وارفع الملف بعد تسميته `index.html`، ثم أكّد الاستبدال/الحفظ. إذا لم يسمح GitHub بالاستبدال، افتح الملف القديم واحذفه أولاً ثم ارفع النسخة الجديدة في نفس عملية التعديل.
4. انتظر انتهاء GitHub Pages ثم افتح الموقع وحدّث الصفحة.

الملف المستقل يضم صور الشعار والواجهة وبطاقات الدروس داخله، فلا تحتاج إلى رفع الصور واحدة واحدة.

## المزايا
- تصميم داكن كحلي وذهبي قريب من الصورة المرجعية ومتجاوب مع الهاتف.
